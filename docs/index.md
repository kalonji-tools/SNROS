# SNROS

Personal NixOS configuration using the [den](https://github.com/denful/den) dendritic framework.

Two x86_64-linux laptops — **dell-xps-9640** and **dell-xps-9500** — configured with ephemeral root (ZFS + Preservation), aspect-oriented modules, and declarative package management.

## Documentation

This site is organized using the [Diataxis](https://diataxis.fr/) framework:

- **[Explanation](explanation/den-patterns.md)** — understand how den aspects, standalone evaluation, and composition work
- **[How-To Guides](how-to/add-a-module.md)** — step-by-step recipes for common tasks

As modules are added, their reference documentation appears under **Reference > Modules**.
